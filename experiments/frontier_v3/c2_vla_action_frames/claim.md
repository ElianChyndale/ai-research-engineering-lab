# C2 Claim — VLA Embodiment / Action-Frame Entanglement

**One-line claim:** Physical robustness failure in VLA policies is partially
caused by semantic task representation being entangled with camera coordinates,
robot embodiment, end-effector coordinates, and/or the action tokenizer, so
semantic-preserving frame transforms cause large equivariance defects that
predict task failure.

**Why the budget is 25%:** high execution risk (frontier VLA checkpoints are
heavy). This branch runs a **feasibility audit + owner audit** first. If a
decisive reproduction needs inaccessible hardware or > reasonable compute →
**E — ACCESS BLOCKED** (not scientific survival).

**Non-goals:** no huge VLA download unless a lightweight reproduction is
decisively feasible; no novelty claim.
